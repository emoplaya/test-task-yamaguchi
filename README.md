# Yamaguchi slider

Тестовое задание: адаптивная вёрстка трёх слайдов, переключение по скроллу и колесо навигации на десктопе.

Демо: https://emoplaya.github.io/test-task-yamaguchi/

## Запуск

```bash
npm install
npm run dev
```

`npm run build` собирает проект в `dist`.

## Стек

Vite, SCSS, GSAP (ScrollTrigger, ScrollToPlugin).
